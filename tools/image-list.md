# Image list (no Python needed)

If you would rather not run `tools/fetch_images.py`, download each image below,
rename it exactly as shown, and upload it to the `src/assets/img/` folder of
your repository. The links open the current WordPress copy.

Tips
- Some WordPress copies are resized (names ending in -1024x576 and similar). For the sharpest result,
  find the original in WordPress under Media > Library and use that instead, with the same new file name.
- `favicon.gif` is your site icon. The page headers expect it at `src/assets/img/favicon.gif`.
- 31 files in total. The build (`python3 build.py`, or the GitHub run log) lists any that are still missing.
